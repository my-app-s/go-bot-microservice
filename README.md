# Go bot microservice
```text
go_bot_project/
├── .env                # Секреты (Токен, Пароли)
├── docker-compose.yml  # Оркестрация контейнеров
├── db_data/            # Данные БД (создастся сама)
└── bot/

    ├── go.mod          # Зависимости
    └── Dockerfile      # Инструкция сборки
```
